### 团队招聘｜杭州 · 实习 / 社招

我们在做能读懂业务上下文的代码评审智能体：给它一段改动，它能不能找到相关实现，说清楚什么场景会出错，而不只是生成行级评论？围绕这个问题，你可以参与：

- **搭建智能体运行框架（harness）**：在 [Open Code Review](https://github.com/alibaba/open-code-review) 中，让智能体能查阅仓库、调用工具，用代码证据支撑评审意见；也和开源社区一起，从实际使用反馈中发现问题。
- **设计评测（benchmark）**：在 [aacr-bench](https://github.com/alibaba/aacr-bench) 中，把真实代码变更做成评测用例，衡量智能体漏掉了哪些缺陷，又给出了哪些误报。
- **与 Qwen 团队联合训练代码评审专用大模型**：围绕真实代码变更构建训练数据，目标是让模型更准确地识别缺陷，同时降低每次评审的推理成本。
